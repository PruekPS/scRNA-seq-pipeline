# Tests

Nothing in `tests/data/` is committed (it is ignored by git); everything is
regenerated by the scripts below.

| File | What it does |
|---|---|
| `integration_smoke.sh` | runs the whole chain (cell-call check → load with sample sheet, plus the optional one-cutoff load from `DGE_unfiltered` → QC → PCA → Harmony by sublibrary → cluster → annotate → TCR → paired pseudobulk DE) on synthetic split-pipe-layout data, then `check_integration.py` compares every result with the planted truth (17 checks) |
| `synthetic_splitpipe.py` | writes WT + TCR data in split-pipe's output layout (`all-sample/` and per-sample `DGE_filtered/` and `DGE_unfiltered/` with planted empty barcodes, `TCR_filtered/` AIRR tables, `__sN` cell names), plus deliberately mis-ordered and per-sublibrary variants, including per-sublibrary runs with one planted unstable cell cutoff |
| `synthetic_tcr.py` | a smaller WT + TCR fixture for scripts 12–13 and 10–11 alone |
| `check_integration.py` | the checks used by `integration_smoke.sh` |

Run on a compute node, inside the `scrna` environment:

```bash
bash tests/integration_smoke.sh tests/data/integration
```

The public 10x PBMC3k dataset is the other standard smoke test:

```python
import scanpy as sc
sc.datasets.pbmc3k().write_h5ad("tests/data/pbmc3k_raw.h5ad")
```

Synthetic data proves the pipeline handles split-pipe's formats and recovers
known signal. It is not a substitute for checking real Parse output. See
[docs/04-test-small-first.md](../docs/04-test-small-first.md).
