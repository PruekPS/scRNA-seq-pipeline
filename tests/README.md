# Tests

Nothing in `tests/data/` is committed (it is ignored by git); everything is
regenerated by the scripts below.

| File | What it does |
|---|---|
| `integration_smoke.sh` | runs the whole chain (cell-call check → load with sample sheet, plus the optional one-cutoff load from `DGE_unfiltered` → QC → PCA → Harmony by sublibrary → cluster → annotate → TCR → paired pseudobulk DE, both `--covariates` and the `--pair-col` shortcut; plus the loader's `--sample-sheet-key` and `--exclude-sublibraries`) on synthetic split-pipe-layout data, then `check_integration.py` compares every result with the planted truth (all checks listed at the end of its output) |
| `synthetic_splitpipe.py` | writes WT + TCR data in split-pipe's output layout (`all-sample/` and per-sample `DGE_filtered/` and `DGE_unfiltered/` with planted empty barcodes, `TCR_filtered/` AIRR tables, `__sN` cell names), plus deliberately mis-ordered and per-sublibrary variants, including per-sublibrary runs with one planted unstable cell cutoff |
| `synthetic_tcr.py` | a smaller WT + TCR fixture for scripts 12–13 and 10–11 alone |
| `check_integration.py` | the checks used by `integration_smoke.sh` |
| `synthetic_tf_activity.py` | toy signed network + DE and pseudobulk inputs with planted TF signal; runs `scripts/14_tf_activity_ulm.py` and checks it recovers activated, repressed and mixed-sign TFs and calls nothing in a null contrast (9 checks, seconds, no internet) |
| `synthetic_orthologs.py` | offline checks of `scripts/14a_fetch_collectri.py`: OmniPath complexes collapse to `AP1`/`NFKB`, and the mouse conversion keeps MGI one-to-one orthologs only (renamed genes, one-to-many families, signs) (6 checks) |
| `synthetic_read_structure.py` | offline checks of `scripts/00d_check_read_structure.py` (a planted short-insert library), the exact tests in `scripts/figstyle.py`, and step 01's mitochondrial rule |
| `synthetic_trajectory.py` | synthetic branching data through `scripts/08` and `09`, run in the `scrna-traj` environment; checks pseudotime follows the planted order and the outputs exist |
| `synthetic_programs.py` | toy data with planted Treg-effector and Th1 cells; checks that `scripts/05c_score_gene_programs.py` scores each program highest in its own cells (mouse and human symbols), the per-sample subset summary, and a custom program CSV (7 checks) |

Run these from the top of the repository, on a compute node, inside the `scrna` environment. Each
creates the folder it is given:

```bash
bash tests/integration_smoke.sh tests/data/integration
python tests/synthetic_tf_activity.py tests/data/tf_activity
python tests/synthetic_orthologs.py tests/data/orthologs
python tests/synthetic_programs.py tests/data/programs
python tests/synthetic_read_structure.py tests/data/read
# in the scrna-traj environment instead:
python tests/synthetic_trajectory.py tests/data/traj
```

The public 10x PBMC3k dataset is the other standard smoke test:

```bash
mkdir -p tests/data
python -c "import scanpy as sc; sc.datasets.pbmc3k().write_h5ad('tests/data/pbmc3k_raw.h5ad')"
```

Synthetic data proves the pipeline handles split-pipe's formats and recovers
known signal. It is not a substitute for checking real Parse output. See
[docs/04-test-small-first.md](../docs/04-test-small-first.md).
